# Explainable AI in Cybersecurity

Dr. Shadrack Oriaro, Ph.D. | [Research profile](https://github.com/DrShadoriaro)

## Research objective

Develop methods for evaluating the usefulness and fidelity of explanations in AI-assisted security decisions.

## Status

Research agenda / proposed development. This repository does not yet contain validated experimental results or released datasets.

## Proposed methodology

Compare baseline classifiers and explanation techniques such as SHAP and LIME using suitable public benchmark data; evaluate fidelity, stability, detection performance and analyst usefulness.
